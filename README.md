## О проекте

Репозиторий с практическими работами, заданиями и отчетами по курсу «Численные методы». 
Включает в себя изучение вычислений с плавающей точкой, оценку погрешностей, работу с рядами, градиентным спуском и другими алгоритмами.

---

## Структура репозитория

| Раздел | Описание |
| :--- | :--- |
| `screens/` | Папка со скриншотами выполненных заданий и графиков. |
| `report.py` | Основной скрипт с решениями задач. |
| `report.md` | Отчет по проделанной работе с выводами и результатами. |
