## Что внутри

Репозиторий с практическими работами, заданиями и отчетами по курсу «Численные методы». Включает в себя изучение вычислений с плавающей точкой, оценку погрешностей, работу с рядами, градиентным спуском и другими алгоритмами.

## Структура проекта

- `screens/` — папка со скриншотами выполненных заданий и графиков.
- `presentations/` — папка с презентациями и теоретическими материалами.
- `report.py` — основной скрипт с решениями задач.
- `report.md` — отчет по проделанной работе с выводами и результатами.
