## Что внутри
Домашняя работа по теме «Устойчивость алгоритма и корректная постановка эксперимента». В работе исследуется разница между обусловленностью математической задачи и вычислительной устойчивостью алгоритма, а также демонстрируются классические примеры потери точности (катастрофическое сокращение, накопление ошибки) и методы их решения.
