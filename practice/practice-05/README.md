## Что внутри
Практическая работа по оптимизации кода на Python с помощью библиотеки NumPy. В 10 задачах сравнивается производительность классических циклов `for` и векторизованных операций NumPy. Для каждой задачи измерено время выполнения и вычислено ускорение.
