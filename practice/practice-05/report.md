## Блок 1. Основные операции


**Задача 1. Сумма массива**

NumPy работает на C под капотом и использует SIMD-инструкции. Ускорение растет с увеличением `n` и становится заметным (>10x) уже на массиве из \(10^5\) элементов.

**Задача 2. Среднее и стандартное отклонение**

NumPy быстрее и точнее. Ручной подсчет через сумму квадратов накапливает ошибку округления, в то время как `np.std()` использует численно устойчивый алгоритм.

**Задача 3. Поэлементное преобразование**

Векторизованные операции (`np.sin(a) + a**2`) избавляют от медленных итераций Python, обрабатывая весь массив целиком на низком уровне.

**Задача 4. Условная замена (clipping)**

Функция `np.clip` заменяет громоздкий цикл с ветвлениями `if/elif` одной короткой командой, которая работает в разы быстрее.


## Блок 2. Агрегации по осям


**Задача 5. Сумма по строкам матрицы**

Использование `m.sum(axis=1)` заменяет двойной цикл одной строкой кода. Время выполнения сокращается в десятки раз, а читаемость повышается.

**Задача 6. Среднее по столбцам и нормировка**

Благодаря механизму broadcasting (автоматическому расширению размерностей) запись `m - m.mean(axis=0)` позволяет вычесть среднее из каждого столбца без явных циклов.

**Задача 7. Поиск максимума и его индекса**

Встроенные функции `a.max()` и `a.argmax()` работают быстрее ручного прохода по массиву с условиями `if`.


## Блок 3. Фильтрация и маски


**Задача 8. Фильтрация по порогу**

Булева маска `a[a > 0]` работает быстрее генератора списков, так как вся фильтрация происходит в C-коде без создания промежуточных Python-объектов.

**Задача 9. Замена по маске (in-place)**

Функция `np.abs(a, out=a)` изменяет массив на месте, не выделяя новую память под результат, что дает значительное ускорение по сравнению с циклом.

**Задача 10. Комбинированная маска**

В NumPy нельзя написать `-1 < a < 1`. Приходится использовать побитовое И (`&`) и расставлять скобки: `(a > -1) & (a < 1)`. Это чуть менее читаемо, чем в Python, но все равно работает быстрее цикла.
