# Переписать обработку массива с циклов на NumPy

## Что внутри

Сравнение производительности чистого Python (циклы) и векторизованных операций NumPy. В работе реализовано 10 задач на базовые операции, агрегации по осям и фильтрацию. Для каждой задачи замеряется время выполнения, рассчитывается ускорение и проверяется совпадение результатов.
