## 1. Свойства массива

Создан массив `arr` формы `(6, 4)`. Выведены его характеристики: 
- `shape`: (6, 4) — количество строк и столбцов.
- `ndim`: 2 — количество измерений.
- `size`: 24 — общее количество элементов.
- `dtype`: int64 (или int32 в зависимости от системы) — тип данных.

## 2. Перестройка формы (reshape)

Массив был успешно перестроен в формы `(4, 6)`, `(2, 3, 4)` и обратно в плоский `(24,)`. Проверка через `np.array_equal` подтвердила, что значения элементов и их порядок не изменились. Метод `reshape` не создает копию, а возвращает представление (view) с новыми индексами.

## 3. Срез (View или копия)

Был взят столбец `col = arr[:, 2]`. При изменении первого элемента среза (`col[0] = 999`) значение изменилось и в исходном массиве `arr`. Это доказывает, что базовые срезы в NumPy возвращают **view (представление)**, а не копию. Копию можно создать только явно через метод `.copy()`.

## 4. Булева фильтрация

С помощью маски `arr > 10` были отфильтрованы элементы. В исходном массиве от 0 до 23 значения больше 10 — это числа с 11 по 23 (всего 13 элементов). Их среднее арифметическое равно 17.0.

## 5. Центрирование по строкам

Для вычитания среднего значения каждой строки использовалась операция `arr.mean(axis=1, keepdims=True)`. Параметр `keepdims=True` критически важен: он сохраняет размерность `(6, 1)`, что позволяет правильно вычесть вектор из матрицы `(6, 4)` по правилам broadcasting. Сумма элементов в каждой строке после центрирования равна 0 (в пределах погрешности float).
