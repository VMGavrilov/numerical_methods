## Что внутри
Практическая работа по изучению базовых операций с многомерными массивами в библиотеке NumPy. В работе рассматривается перестройка формы (reshape), проверка изменения значений, работа с представлениями (views) и копиями, булева фильтрация, а также вычисление среднего и центрирование данных по осям.
