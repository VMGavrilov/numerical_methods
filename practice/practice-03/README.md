## Что внутри

Практическая работа по исследованию «катастрофического сокращения» (catastrophic cancellation) при работе с числами с плавающей точкой. В работе сравниваются два математически эквивалентных способа вычисления функции \(\sqrt{x+1} - \sqrt{x}\): прямое вычитание и умножение на сопряженное.
