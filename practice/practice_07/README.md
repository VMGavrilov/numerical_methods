## Что внутри

Сравнение производительности базовых структур данных и способов построения списков на чистом Python. В работе реализовано 2 задачи: сравнение скорости поиска элемента в `list` и `set` (с замерами при разных размерах коллекции и построением графика роста времени) и сравнение трёх способов создания списка квадратов (цикл с `append`, list comprehension, `map` + lambda) по времени выполнения и пиковой памяти. Для каждого эксперимента замеряется время, рассчитывается ускорение и визуализируются результаты на графиках.
