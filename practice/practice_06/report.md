# Отчет по домашнему заданию «Циклы vs NumPy»

## Блок 1. Основные операции

**Задача 1. Сумма массива**

Ускорение NumPy напрямую зависит от размера массива. При \(n = 10^5\) разница минимальна, но начиная с \(n = 10^6\) она уверенно превышает 10×, а на \(n = 10^7\) достигает десятков раз. Это связано с тем, что циклы Python интерпретируются построчно, а NumPy выполняет векторизованные операции в скомпилированном C-коде, минимизируя накладные расходы.

**Задача 2. Среднее и стандартное отклонение**

Результаты совпадают до \(10^{-12}\). Использование `mean()` и `std()` не только в разы быстрее, но и математически точнее, так как NumPy использует оптимизированные алгоритмы (например, парное суммирование для снижения ошибки округления).

**Задача 3. Поэлементное преобразование \(\sin(x) + x^2\)**

Векторизация `np.sin(a) + a**2` дает колоссальное ускорение по сравнению с вызовом `math.sin()` в цикле. Код становится в одну строку, что повышает читаемость.

**Задача 4. Условная замена (clipping)**

Функция `np.clip(a, 0, 1)` справляется с задачей в десятки раз быстрее, чем цикл с `if/elif/else`. Побочная статистика `np.sum((a < 0) | (a > 1))` легко вычисляется через булевы маски.

## Блок 2. Агрегации по осям

**Задача 5. Сумма по строкам матрицы**

Параметр `axis=1` в `m.sum(axis=1)` позволяет избавиться от вложенных циклов. Код на NumPy занимает 1 строку вместо 5, а работает быстрее в силу оптимизации C-кода.

**Задача 6. Среднее по столбцам и нормировка**

Broadcasting (`m - m.mean(axis=0)`) — мощный инструмент. Вместо того чтобы вручную вычитать среднее из каждого элемента в цикле, NumPy автоматически "растягивает" вектор средних на всю матрицу. Читаемость и скорость возрастают на порядки.

**Задача 7. Поиск максимума и его индекса**

Метод `argmax()` мгновенно находит индекс максимального элемента, избавляя от ручного перебора с обновлением переменных `max_val` и `max_idx`.

## Блок 3. Фильтрация и маски

**Задача 8. Фильтрация по порогу**

`a[a > 0]` работает быстрее генератора списков (`[x for x in a if x > 0]`) и сразу возвращает `ndarray`. Память также расходуется эффективнее, так как не создаются промежуточные объекты Python (int/float).

**Задача 9. Замена по маске (in-place)**

Операция `arr[arr < 0] *= -1` изменяет массив на месте (in-place) без создания нового объекта. Цикл с `if` вынужден проходить по каждому элементу, что сильно замедляет процесс.

**Задача 10. Комбинированная маска**

В Python условие `-1 < x < 1` читается естественно, но в NumPy его нужно разбивать на `(a > -1) & (a < 1)`. Скобки обязательны из-за приоритета операторов. Несмотря на то, что запись стала чуть многословнее, она работает в разы быстрее цикла.
