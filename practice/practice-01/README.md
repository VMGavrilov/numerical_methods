## Что внутри

Практическая работа по оценке точности вычислений с плавающей точкой. В коде реализована функция для расчета относительной и абсолютной погрешности, которая затем проверяется на трех кейсах: приближение числа \(\pi\), классическая ошибка сложения `0.1 + 0.2` и накопление ошибки при сложении миллиона элементов.
